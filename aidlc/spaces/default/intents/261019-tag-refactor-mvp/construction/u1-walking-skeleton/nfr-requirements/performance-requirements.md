# 性能の要件: U1 最小の一本

出典: 要件 NFR1、`nfr-requirements-questions.md`(決まっていること)、機能設計 `functional-spec.md`。

U1 は1つのリージョンだけを読むため、要件 NFR1(全リージョン1万件で、scan と plan を合わせて10分以内)の目標は、全リージョンを読む U2 が受け持ちます。U1 では、後で見積もるための測り方を用意します。

| ID | 要件 | 合否の基準 |
|---|---|---|
| NFR1.1 | scan と plan は、終わりに、かかった時間と調べたリソースの件数を標準エラーに出す | 検証用アカウントでの実行で、時間と件数が表示される |
| NFR1.2 | 検証用アカウントでの U1 の検証の結果(リージョン、リソースの件数、かかった時間)を、U1 のチェックポイントの記録に残す。U2 が NFR1 を見積もる材料にする | チェックポイントの記録に3つの値がある |
| NFR1.3 | タグの読み取りと、IAM のポリシーの読み取りは、ページが分かれていても最後まで読む。1件ずつ取り直すような読み方はしない(1ページで取れるものはまとめて取る) | 差し替えた AWS で、ページが3つに分かれた応答を最後まで読むテストが通る |

## 目安

- U1 の検証用アカウントの規模(数百件程度)では、scan と plan はそれぞれ1分以内に終わることを目安にします。これは合否の基準ではなく、大きく外れたら U2 の前に原因を調べるための目安です。
