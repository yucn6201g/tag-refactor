決まっていること(質問しません):

- 言語は Go、配るのは1つの実行ファイル(要件 CON1、NFR9)。AWS へのアクセスは AWS の公式の Go 用 SDK(v2)を使う。

## Consolidated Summary Confirmation

回答のまとめ:

- 読み取り用の IAM ポリシーの例(Q4): U1 から用意します。U1 が呼ぶ API だけを並べた例をリポジトリに置き、API を足すたびに更新します。検証用アカウントでの確認にも使います。
- 性能(質問なし): U1 は1つのリージョンだけなので、かかった時間を測って記録します。NFR1 の目標は U2 が受け持ちます。
