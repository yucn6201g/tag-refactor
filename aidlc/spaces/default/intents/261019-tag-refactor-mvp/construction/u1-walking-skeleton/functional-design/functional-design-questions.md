# 機能設計 — 質問(U1 最小の一本)

U1 は、端から端まで動く最小版です。`scan` と `plan` の最小版、ビルド、テスト、lint、CI を含み、個人の検証用 AWS アカウントで動くことを確かめます(`inception/units-generation/unit-of-work.md`、`inception/delivery-planning/bolt-plan.md` の B1)。

決まっていること(質問しません):

- U1 の `plan` は、ルールファイルのキーの別名(`keys.<正しいキー名>.aliases`)だけを読み、キー名の変更だけを作ります。値の変更、必須タグ、削除は U3・U4 で足します。
- U1 の影響分析は、IAM の管理ポリシーの、リソースのタグの条件キー(`aws:ResourceTag/<キー>` とサービス固有の `<サービス>:ResourceTag/<キー>`)だけを照合します。
- IAM の条件では、タグのキーの大文字・小文字は区別されず、値は区別されます(AWS のドキュメント「AWS global condition context keys」の `aws:ResourceTag/tag-key`)。そのため、`env` → `Env` のような大文字・小文字だけの名前の変更は、キーの条件には影響しないと判定します。
- 出力は端末向けの一覧の形だけ、言語は英語だけです(4つの形式と日本語は U4)。
- 一度もタグが付いていないリソースの検出は U2 で足します。U1 はタグの付いたリソースだけを読みます。
