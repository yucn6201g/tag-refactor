# インフラの設計 — 質問(U6 書き換えと記録)

U6 のチェックポイントで、検証用アカウントのタグを実際に書き換えて確かめる方法を決めます。

決まっていること(質問しません):

- CI/CD の流れ(`ci.yml` のジョブ、`ci-gate`、`race`、関門)と検証コマンド(`scripts/verify.sh`)は U1〜U5 のまま。CI から実際の AWS は呼ばない。
- 確かめること(NFR の設計): 書き換え用の権限の例で、確認用のスタックにある種類(S3 のバケット、SQS、SNS、Secrets Manager、IAM のロール、EC2 のセキュリティグループ)を1件ずつ書き換えて戻す。一度もタグのないリソースが `GetResources` の答えに出るかを確かめる。`--debug` を5回動かして L95 を測り、30分の見積もりを出す。
- CloudFormation が作るリソースには `aws:cloudformation:*` のタグが自動で付くため、一度もタグのないリソースはスタックでは作れない。U2 と同じく、検証のスクリプトが一時的に作って最後に消す。
- 検証用アカウントへの変更(スタックの作成・更新)は、変更セットを作って中身を示し、人の許可を得てから実行する(U5 と同じ手順)。
