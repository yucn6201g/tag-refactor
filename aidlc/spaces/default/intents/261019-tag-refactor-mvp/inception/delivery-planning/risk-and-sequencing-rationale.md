# 順番の理由と危険: tag-refactor

Bolt(作業の一部を設計から実装まで一通り作り、動くものができるところまで進める1回分の作業)を、なぜこの順番にしたかを残します。

## 使った考え方

- **最小の一本を最初に作る:** 最小の一本(walking skeleton)は、端から端まで動く最小版のことです。チームの進め方(§Walking Skeleton)で、最初の作業単位を最小の一本にすると決めています。部品の分け方、インターフェース、CI の仕組みの誤りを、最初の Bolt で見つけるためです。
- **段階の順を守る:** 第1弾(`scan`、`plan`)、第2弾(`apply`、`rollback`)、第3弾(IaC への反映)の順に作ります。第1弾は読み取りだけで安全に使え、`v0.1.0` として早く公開できるためです(`delivery-planning-questions.md` Q1)。
- **段階の中では危険の大きいものを先に作る:** 依存関係が許す範囲で、確かめるのが難しいものを先にします(Q1、Q6)。Mike Cohn の「危険の大きい、価値の大きいものを先に」という考え方の、危険の側を使っています。
- **点数は付けない:** WSJF(価値、急ぎ具合、危険の減り方を、大きさで割った点数で順番を決める方法)は使いません(Q2)。作業単位の依存関係がほぼ1本の列で、順番を変えられるところが少ないためです。

## 順番を変えられるところと、選んだ順番

依存関係(`inception/units-generation/unit-of-work-dependency.md`)で、順番を選べるのは次の2か所だけです。

| 選べるところ | 選んだ順番 | 理由 |
|---|---|---|
| U2 と U3(どちらも U1 だけに依存) | U2 を先 | U2 には、1万件を10分以内に読む性能と、AWS の呼び出し回数の上限という、確かめるのが難しい危険があります(Q6 B)。U3 は AWS を呼ばず、手元のファイルだけでテストできます |
| U8(U4 の後ならいつでも作れる) | 最後 | 第3弾として計画しているためです。詳しい振る舞いが未決(要件 OQ3)で、規模も XL です。U5〜U7 より先にすると、第1弾と第2弾の公開が遅れます |

依存関係の順番から外れた Bolt はありません。

## 心配なことと、確かめる Bolt

人が「早めに確かめたい」と選んだ4つ(Q6)を、次の Bolt で扱います。

| 心配 | 確かめる Bolt | 早めに確かめる工夫 |
|---|---|---|
| 影響分析の検出の正確さ(検出率100%) | B1(最小版)、B5 | B1 で IAM の管理ポリシーの照合の最小版を作り、照合の仕組みが成り立つかを最初に確かめます。B5 では、テスト用のポリシーの集まりで検出率を測ります |
| 1万件を10分以内に読む性能と、呼び出し回数の上限 | B2 | 第1弾の2番目に作ります。AWS の呼び出しを差し替えた1万件の模擬データで測り、実際の呼び出し回数の上限は検証用アカウントで確かめます |
| apply と rollback の安全さ | B6、B7 | 契約の設計で、途中で止まった apply を戻すための記録の形を先に決めました(契約 C4)。B6 と B7 は続けて作り、検証用アカウントで途中の失敗を起こして確かめます |
| IaC への反映の不確かさ | B8 の前の設計 | 第3弾に取りかかる前に、詳しい振る舞い(要件 OQ3)を設計します。第3弾の前に、もう一度計画を見直します |

## その他の危険

| 危険 | 影響する Bolt | 対応 |
|---|---|---|
| 開発用の道具(Go、golangci-lint、govulncheck、gh)が手元にない | B1 | B1 の前に入れます(`external-dependency-map.md` の E1) |
| CI の Windows で、改行コードやパスの違いでテストが失敗する | B1 以降 | B1 で `.gitattributes` を入れ、最初から3つの OS で CI を実行します |
| 検証用アカウントの費用 | B2、B5、B6、B7 | AWS Config などの費用がかかるものは、確かめるときだけ有効にし、終わったら止めます |
| エンジンが U3 を U2 より先に提示する | B2、B3 | 依存関係からはどちらも選べるため、提示されたらその場で U2 を先にするよう求めます(`bolt-plan.md`) |
| `v0.1.0` の公開には、作業単位の外の配布の仕組みが必要 | B5 の後 | 第1弾の完成後に、別の作業として作ります(E6) |
