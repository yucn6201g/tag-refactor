# 表示の決まり(デザインシステムの対応): tag-refactor

コマンドラインのツールなので、画面の部品集の代わりに、出力の決まりをまとめます。既存のデザインシステムはありません。

## 記号

| 記号 | 意味 | 使う場所 |
|---|---|---|
| `+` | タグを追加する | plan、apply |
| `~` | キー名または値を変える | plan、apply |
| `-` | タグを消す | plan、apply |
| `!` | 影響あり、または結果が不完全(要確認) | plan、apply、scan |
| `?` | 判定できない | plan、apply |
| `>` | 飛ばした | apply、rollback |
| `x` | 失敗した | apply、rollback |
| `[done]` `[running]` `[waiting]` | リージョンの状態 | scan、plan |

## 色(補助のみ)

| 意味 | 色 | 色がないときの代わり |
|---|---|---|
| 追加 | 緑 | `+` |
| 変更 | 黄 | `~` |
| 削除・失敗 | 赤 | `-`、`x` |
| 影響あり・不完全 | 赤の太字 | `!` と文字 |
| 判定できない | 黄の太字 | `?` と文字 |
| 補足 | 薄い灰色 | なし(情報は文字で伝わる) |

- `NO_COLOR` 環境変数があるとき、または出力先が端末でないときは、色を出しません。

## 出力先と形式

| 出力 | 出力先 | 形式 |
|---|---|---|
| 結果 | 標準出力 | 一覧(既定)、差分、JSON、Markdown |
| 進み具合 | 標準エラー | 端末では書き換え表示、端末でないときは1行ずつ追記 |
| 案内、警告、エラー | 標準エラー | 文章 |
| 変更案の保存 | `--out` のファイル | JSON |
| 書き換える前の記録 | 手元のファイルまたは S3 | JSON |
| ルールファイル | 利用者が編集するファイル | YAML |

## 文言の書き方

- エラーは、1行目に何が起きたか、2行目に直し方を書きます。
- 何も変えなかったときは、「Nothing was changed.」と必ず書きます。
- 最後の行で、次にすることを1つだけ示します。
- 英語と日本語で同じ情報を出します。数字、ARN、ポリシー名、オプション名は訳しません。

## 終了コード

| コード | 意味 |
|---|---|
| 0 | 問題なし |
| 1 | エラー、結果が不完全、一部が失敗 |
| 2 | 問題や影響あり、飛ばしあり、確認を省いたときに影響のある変更で止まった |

詳しくは `mockups.md` の §1 を参照してください。
