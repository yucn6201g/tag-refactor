# 信頼性の要件: U1 最小の一本

元になる要件は `inception/requirements-analysis/requirements.md` の NFR3〜NFR9、決まりは `construction/u1-walking-skeleton/functional-design/rules.md` です。この道具は利用者が手で動かす CLI なので、可用性の SLA は置きません。ここでは、途中で止まったときに半端な状態を残さないこと、今の振る舞いを壊さないこと、テストで守ることを決めます。

## 途中の失敗と後片付け

| ID | 要件 | 合否の基準 | 出典 |
|---|---|---|---|
| NFR4.1 | CDK のソースの書き換えも、今の `iac` と同じく一時ファイルに書いて名前を変える形で行い、途中で失敗したら、書いたファイルと書いていないファイルを示す | 2つ目のファイルの書き出しを失敗させるテストで、半分だけ書かれたファイルが残らず、書いたファイルが示される | NFR4 |
| NFR4.2 | 書き出しが途中で失敗したか中断されたときは、ブランチ、コミット、push、プルリクエストの作成に進まない | 同じテストに `--pr` を付けて、`git` と `gh` が呼ばれないことを確かめる | NFR4、BR4.2 |
| NFR4.3 | synth の出力、認証情報の遮断の一時ファイル、補助のプログラムの書き出し先は、成功、失敗、Ctrl+C の中断のどれでも消す | 中断を含むテストで、一時的なフォルダーが残らない | NFR4、FR2.6 |
| NFR4.4 | ブランチの作成のあとの段階で失敗しても、済んだことは元に戻さず、済んだ段階と失敗した段階を示して終了コード 1 にする | push のあとで `gh` を失敗させるテストで、手元のブランチとコミットが残り、終了コードが 1 | FR1.12 |
| NFR3.10 | 外のプログラムを止めるときは、子のプロセスごと止める(Windows ではプロセスの木を止める)。止めたあと、待ち続けない | 終わらない差し替えのプログラムのテストで、上限のあと一定の時間(5 秒)の中で戻る | NFR3 |

## 今の振る舞いを壊さない

| ID | 要件 | 合否の基準 | 出典 |
|---|---|---|---|
| NFR5.2 | CDK のアプリが無いときと `--pr` を付けないときの `iac` の出力、終了コード、AWS の認証情報が要らないことは変えない | 前の intent の `iac` の受け入れ条件のテストが、すべてそのまま通る | NFR5 |
| NFR6.1 | Linux、macOS、Windows で、`CGO_ENABLED=0` の単一のバイナリとして動く。補助のプログラムはバイナリに埋め込む | 3つの OS の CI で、`CGO_ENABLED=0` のテストが通る | NFR6 |

## テストで守るもの

| ID | 要件 | 合否の基準 | 出典 |
|---|---|---|---|
| NFR7.1 | 文のカバレッジ 80% 以上。`cdk`、`node`、`git`、`gh` を呼ぶ部分も計測から外さず、差し替えた実行の口でテストする | CI のカバレッジの確かめが通る | NFR7 |
| NFR8.1 | `cdk synth` を動かすテストを、CI の3つの OS で実行する。Node.js、CDK の CLI、テスト用のアプリの `node_modules` のどれかが無いとき、CI(環境変数 CI が空でない)では失敗、手元では理由を出して飛ばす | CI に道具が無いと失敗になることを、CI の定義で確かめる | NFR8、BR5.1 |
| NFR8.2 | テスト用のアプリの npm の依存と CDK の CLI は、`package-lock.json` で版を固定し、Dependabot で更新する。CI はテストの前に `npm ci` を実行する | Dependabot の設定と CI の定義の確かめ | NFR8、チームの進め方 |
| NFR9.1 | 実際の GitHub にプルリクエストを作る結合テストは、`TAG_REFACTOR_TEST_REPO` と `TAG_REFACTOR_TEST_REPO_TOKEN` の両方が空でないときだけ実行し、作ったプルリクエストを閉じ、ブランチを消す。片付けに失敗したら、残したものの名前を出してテストを失敗にする | secret のある CI で、テスト専用のリポジトリにプルリクエストができ、テストのあとで消える。secret の無い実行では飛ばされる | NFR9、BR5.2 |
