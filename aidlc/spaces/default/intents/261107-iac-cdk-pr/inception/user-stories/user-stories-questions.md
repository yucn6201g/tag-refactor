## Q4. プルリクエストを作る先のリモート

A. 今のブランチの追跡先のリモートを使い、無ければ `origin` を使う。どちらも決まらなければ、書き換えの前に止める。base のブランチがリモートに無いときも、書き換えの前に止める
B. いつも `origin` を使う。base のブランチがリモートに無ければ、書き換えの前に止める
C. オプションで指定でき、既定は `origin`。base のブランチがリモートに無ければ、書き換えの前に止める
D. 任せる
