# 利用者像: iac への CDK の反映とプルリクエストの作成

## P1: 佐藤さん(プラットフォームの担当)

前の作業(`261019-tag-refactor-mvp`)の P1 と同じ人です(意図の段階の Q2)。

| 項目 | 内容 |
|---|---|
| 役割 | AWS のタグを整理し、IaC も直すプラットフォームの担当。CDK で作ったリソースを持つチームも受け持つ |
| 目的 | (1) `apply` で変えたタグが、次の `cdk deploy` や `terraform apply` で元に戻らないようにする。(2) IaC の修正を、手作業を減らしてチームのレビューに出す |
| 困りごと | 今の `iac` は CDK のリソースを「手で直す一覧」に出すだけで、CDK のソースは手で直している。書き換えたあと、ブランチ、コミット、push、プルリクエストの作成を手で行っている |
| 技術への慣れ | 高い。AWS、git、GitHub、CDK(TypeScript と Python)、Terraform、CloudFormation を使う |
| 使う頻度 | タグを整理するときに、`plan`、`apply` のあとで使う |
| 端末の環境 | Node.js、CDK の CLI、`gh` が入っている(要件の仮定 A1)。Python の CDK のアプリを扱うときは Python も |
